## Publicação no GitHub Pages
1. Extraia o ZIP.
2. Envie todos os arquivos e a pasta `icons` para a raiz do repositório.
3. Em **Settings > Pages**, selecione a branch `main` e `/(root)`.
4. Abra o endereço HTTPS no celular.
5. Toque em **📲 Instalar Merox Gasolina concept**.

### Se o celular mostrar versão antiga
Altere o `CACHE_NAME` do `sw.js` de:
`merox-gasolina-concept-v1`
para:
`merox-gasolina-concept-v2`

Depois publique novamente e reabra o navegador.
